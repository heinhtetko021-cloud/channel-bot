## ⚙️ Customize (Template တိုင်း တူ)

1. **CSS variables** (အပေါ်ဆုံး `<style>` — theme အရောင်ပြောင်း)
2. **JS CONFIG** (အပေါ်ဆုံး `<script>` — နာမည်/ဖုန်း/TG link)
3. **Content array** (`PRODUCTS`/`SERVICES`/`MENU`/`GAMES`...) — data ထည့်/ဖျက်

> အားလုံး `t.me/hein_public_ai_bot` Telegram confirm နဲ့ ချိတ်ထားပြီးသား။
